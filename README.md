# LUUX 경쟁매체 광고 현황

공유 주소: https://yjseo5589-create.github.io/luux-dashboard/

이 저장소는 화면 코드만 제공합니다. 조사 원문·광고주 DB·인증값·스냅샷은 저장하지 않습니다. 운영 서버가 입력 시트를 직접 읽어 세 화면에 필요한 결과를 전달하며 화면은 30초마다 확인합니다. 저장소의 쓰기·배포 권한은 소유자만 갖습니다. 다른 방문자는 웹을 열람할 수 있지만 원본 시트를 수정하거나 배포할 수 없습니다.

화면 변경: index.html 수정 → npm test → main push → GitHub Pages 자동 배포. 데이터 변경: 기존 입력 시트 수정. 서버와 자동화의 소스는 비공개 luux-competitor-report/web 에서 관리합니다. 서버 코드 변경은 Sites 배포를 별도로 확인해야 합니다.

GitHub Pages는 공개 웹입니다. 링크 보유자 제한 인증은 없으며 robots 설정은 접근 제어가 아닙니다.
